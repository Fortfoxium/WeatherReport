# WeatherReport
Для сдачи дисциплины "Проектный практикум" 
Студент Антипин Владислав Денисович 23-ЗИЭ-1
Программа WeatherReport, сделанная мной по концепту моей девушки, показывает температуру, погоду, влажность, уф-индекс, ветер  в конкретных координатах.
Программа использует сервис API Яндекс погода. К сожалению api-ключ выдаётся только на 7 дней, поэтому после 7 апреля он станет недействителен.
При запуске приложение сворачивается в системный трей, т.к. мне показалось это удобным и удачным решением. 
В системном трее можно правой кнопкой вызвать меню: "Показать", "Выход", "Настройки"
</p>
Выход - это закрытие приложения
</p>
Показать - это отображение главного окна приложения
</p>
Настройки - открывает окно настроек в котором можно ввести координаты места на планете и ввести API ключ, т.к. я не знал с самого начала про то что этот API ключ временный, пришлось сделать такой формат, чтобы в будущем при доработках приложения я мог вводить новые временные ключи, в итоговом варианте, конечно, эта функция не нужна
</p>
Если взглянуть на главное окно то можно сразу увидеть все основные данные погоды, а также дополнительно время и время последнего обновления данных(Тут же кнопка обновления данных, которая посылает, после нажатия, API запрос)
